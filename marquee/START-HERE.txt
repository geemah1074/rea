  MARQUEE DIGITAL SIGNAGE  -  START HERE
======================================================================

HOW TO USE THIS GUIDE
- Do the steps in order. Do not skip ahead.
- Every step tells you:
    DO        what to click or type
    YOU SEE   what the screen should look like after
    IF NOT    what to do when it looks different
- Keep a Notepad window open to write down 4 things as you go:
    1. Your Supabase Project URL      (Step 7)
    2. Your Supabase anon key         (Step 7)
    3. Your website address           (Step 11)
    4. The email you use for the studio (Step 6)
- Stuck? Use ChatGPT (Part A) and the ready-made prompts (Part K).

WHAT THIS IS
Marquee shows pictures, videos, web pages and text messages on screens
(your Android tablet, or a TV plugged into your Windows PC), and lets
you change them from anywhere.

  THE STUDIO  = the website where you manage everything
                https://YOUR-SITE.pages.dev/
  THE PLAYER  = the page you open on each screen
                https://YOUR-SITE.pages.dev/player/
  SUPABASE    = the free online "brain" that stores everything
  CLOUDFLARE  = the free service that puts the website online

You need: a Windows PC, the Android tablet, your Supabase account,
your Cloudflare account, and about 45 minutes.

HOW THE SYSTEM WORKS
- Folders inside "marquee":
    START-HERE.txt          the step-by-step guide I am following
    supabase/schema.sql     run once in the Supabase SQL Editor
    web/                    the whole website, uploaded to Cloudflare Pages
                            using "Drag and drop your files"
      index.html, studio.js, studio.css   = THE STUDIO (admin website)
      player/               = THE PLAYER (opened on each screen)
      shared/config.js      = the ONLY file I edit: Supabase URL + anon key
      shared/vendor/supabase-2.45.4.js = Supabase JavaScript library
    windows/start-player.cmd       opens the player full screen in Edge
    windows/install-autostart.ps1  starts the player when Windows starts
- It is a plain static website. No build step, no server code.
- Studio: https://<site>.pages.dev/   Player: https://<site>.pages.dev/player/
- Supabase gives: login, Postgres database, private storage bucket
  "media", and Realtime (live updates).

DATABASE (made by supabase/schema.sql)
- Tables: admin_allowlist(email), assets (image, video, web, text),
  playlists, playlist_items (position, duration_s, optional days,
  start_time, end_time, start_date, end_date), screens (name,
  playlist_id, rotation, fit, last_seen, status, content_version),
  pairings (6-character codes), commands (reload, refresh, identify,
  clear_cache).
- Functions: is_admin(), device_start_pairing(), claim_screen(code,name),
  device_heartbeat(status), device_ack_command(id).
- Row Level Security is ON everywhere. Only emails in
  public.admin_allowlist can use the studio. A screen can only read its
  own playlist and media and can never change anything.

HOW A SCREEN WORKS
1. The player signs in to Supabase ANONYMOUSLY ("Allow anonymous
   sign-ins" must be ON) and shows a 6-character code.
2. In the studio: "Add screen", type the code and a name, "Pair screen".
3. The player downloads its playlist and media, saves them on the
   device, and plays full screen. It keeps playing if the internet drops.
4. Every 30 seconds it reports back. The studio shows ON AIR (seen in the
   last 75 s), NOT SEEN (up to 10 min) or OFFLINE.
5. Changes reach screens instantly (Realtime) or within 15 s (polling).

MESSAGES AND THEIR MEANING
- "Setup needed ... placeholder values": config.js not filled in, or not
  uploaded to Cloudflare again after editing.
- Player "Cannot sign in this player": anonymous sign-ins are OFF.
- Studio "This account is not on the studio allowlist": run the SQL line
  it shows in the Supabase SQL Editor.
- Studio "Could not check access ... Did you run supabase/schema.sql?":
  schema.sql not run, or config.js points at a different project.
- Upload fails: Supabase free plan allows 50 MB per file.
- Web page item is blank: that site refuses to be shown inside pages.

======================================================================
  PART B - SUPABASE (the "brain")
======================================================================

STEP 1. Unzip the file.
  DO      Right-click the zip file > "Extract All..." > "Extract".
  YOU SEE A folder called "marquee". Inside it: START-HERE.txt, and the
          folders "supabase", "web", "windows" (and a few others you can
          ignore).
  IF NOT  If you only see one folder inside another, open it until you
          see those folders.

STEP 2. Create a Supabase project.
  DO      a. Go to https://supabase.com/dashboard and sign in.
          b. Click "New project".
          c. Project name: marquee
          d. Database password: click "Generate a password". Copy it into
             Notepad and keep it safe (you will rarely need it).
          e. Region: pick the one closest to you.
          f. Click "Create new project".
          g. WAIT 2 to 3 MINUTES. Do not close the page.
  YOU SEE When it is ready, the "Setting up project" message is gone and
          you see the project home page with a menu down the left side
          (Table Editor, SQL Editor, Authentication ...) and a green
          "Connect" button at the top.
  NOTE    You do NOT need to click "Connect" now. Go to Step 3.

STEP 3. Create the database (copy and paste one file).
  DO      a. In File Explorer open  marquee > supabase.
          b. Right-click "schema.sql" > "Open with" > "Notepad".
             (If Notepad is not listed: "Choose another app" > Notepad.)
          c. In Notepad press Ctrl + A, then Ctrl + C.
          d. In Supabase, left menu: click "SQL Editor".
          e. Click "New query" (or the "+" button).
          f. Click inside the big empty box and press Ctrl + V.
          g. Click the green "Run" button (bottom right) or press
             Ctrl + Enter.
  YOU SEE Under the box: "Success. No rows returned".
  IF NOT  - A pop-up warns about "destructive operations": click
            "Run this query". It is safe (the file only replaces its own
            rules).
          - Red error text: copy it and use PROMPT 3 (Part K).

STEP 4. Turn ON anonymous sign-ins (screens need this).
  DO      a. Left menu: "Authentication".
          b. Click "Sign In / Providers" (sometimes just "Providers" or
             "Settings").
          c. Find "Allow anonymous sign-ins" and switch it ON (it turns
             green).
          d. If there is a "Save" button on that section, click it.
  YOU SEE The switch for "Allow anonymous sign-ins" is green/ON.
          On the same page "Email" is enabled (it is ON by default).
  IF NOT  If you cannot find it, use PROMPT 2 with a photo.

STEP 5. (Optional but easier) Turn off email confirmation.
  WHY     Otherwise Supabase emails you a confirmation link when you
          create your studio account. Free Supabase only sends a few
          emails per hour and they can land in spam.
  DO      Same page as Step 4, click "Email" to open its settings.
          Turn OFF "Confirm email". Click "Save".
  NOTE    If you skip this step, that is fine. Step 13 explains what to
          do with the email.

STEP 6. Allow YOUR email to use the studio.
  DO      a. Left menu: "SQL Editor" > "New query".
          b. Copy this line into the empty box:

             insert into public.admin_allowlist (email) values ('your.email@example.com');

          c. Replace  your.email@example.com  with YOUR email, in
             small letters, keeping the ' marks on both sides.
          d. Click "Run".
          e. Write this email in your Notepad. You must use exactly this
             email in Step 13.
  YOU SEE "Success. No rows returned".
  IF NOT  "duplicate key": it was already added. That is fine.

STEP 7. Copy your Project URL and anon key.
  DO      a. Click the green "Connect" button at the top of the project
             page. Look for a tab like "App Frameworks" or "API Keys".
             It shows two values:
               - a URL like  https://abcdefghijklmnop.supabase.co
               - a long key (the ANON key starts with "eyJ"; a
                 PUBLISHABLE key starts with "sb_publishable_")
          b. Copy both into your Notepad.
          c. Close the Connect box.
          OTHER PLACE TO FIND THEM: left menu (bottom) gear icon
          "Project Settings" > "API Keys" (the anon key may be on a tab
          called "Legacy API Keys"). The Project URL is also under
          "Project Settings" > "Data API".
  WHICH KEY? Use the "anon" key (starts with eyJ) if you can find it.
          If not, use the "publishable" key.
  NEVER   copy the "service_role" key or "Secret key". They are private
          and this app does not need them.

  PART C - PUT YOUR KEYS INTO THE APP

STEP 8. Edit config.js.
  DO      a. In File Explorer open  marquee > web > shared.
          b. Right-click "config.js" > "Open with" > "Notepad".
  YOU SEE Something like this:

          window.MARQUEE_CONFIG = {
            supabaseUrl: "https://YOUR-PROJECT-REF.supabase.co",
            supabaseAnonKey: "YOUR-ANON-OR-PUBLISHABLE-KEY",

  DO      c. Replace  https://YOUR-PROJECT-REF.supabase.co  with your
             Project URL.
          d. Replace  YOUR-ANON-OR-PUBLISHABLE-KEY  with your key.
          e. Keep the " quote marks and the comma at the end of each line.
  YOU SEE Something like (with your own values):

          window.MARQUEE_CONFIG = {
            supabaseUrl: "https://abcdefghijklmnop.supabase.co",
            supabaseAnonKey: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
          };

  DO      f. Press Ctrl + S to save. Close Notepad.
  CHECK   No spaces inside the quotes, and the URL starts with https://

  PART D - CLOUDFLARE (put the website online)
======================================================================

STEP 9. Start a new Pages project.
  DO      a. Go to https://dash.cloudflare.com and sign in.
          b. Left menu: "Workers & Pages" (may be under "Compute" or
             "Build").
          c. Click "Create" (or "Create application").
          d. Choose the "Pages" tab. If you only see Workers, click the
             link "Looking to deploy Pages? Get started".
  YOU SEE A page titled "Get started" with TWO choices:
            - "Import an existing Git repository"
            - "Drag and drop your files"
  DO      e. Click "Get started" next to "Drag and drop your files"
             (the SECOND one). Do NOT choose the Git one.

STEP 10. Name it and upload.
  DO      a. Project name: marquee-signage
             (small letters and dashes only).
          b. Click "Create project".
          c. An upload box appears. In File Explorer open the "marquee"
             folder and DRAG THE "web" FOLDER onto the box.
             (If it asks you to pick a folder, pick "web".)
          d. Wait until all files are uploaded (around 20 files).
          e. Click "Deploy site".
  YOU SEE "Success" and your website address, for example
          https://marquee-signage.pages.dev
          (If that name was taken, Cloudflare adds letters to it.)

STEP 11. Open your website.
  DO      a. Write the address in your Notepad.
          b. Open it in a new browser tab.
  YOU SEE A page split in two:
            - LEFT (dark): "MARQUEE" and big text
              "Every screen, from one desk."
            - RIGHT (light): "Sign in to the studio", Email and Password
              boxes, an orange "Sign in" button and the link
              "First time? Create the owner account".
  IF NOT  - "404" or "Not found": the files went one folder too deep. In
            Cloudflare open your project > "Create deployment" > open the
            "web" folder, select everything INSIDE it (Ctrl + A), drag
            those in, Deploy. Try the address again.
          - "Setup needed ... placeholder values": config.js was not saved
            before uploading. Do Step 8 again, then re-upload (Step 27).
          - Page loads but looks plain/unstyled: wait 1 minute and press
            Ctrl + F5.

  PART E - YOUR STUDIO ACCOUNT
======================================================================

STEP 12. Tell Supabase your website address. (Do this BEFORE Step 13.)
  DO      a. Supabase > left menu "Authentication" > "URL Configuration".
          b. "Site URL": paste your website address
             (for example https://marquee-signage.pages.dev).
          c. Click "Save".
  WHY     The confirmation email link sends you to this address.

STEP 13. Create your owner account.
  DO      a. On your website, click "First time? Create the owner account"
             (under the orange button).
          b. Email: EXACTLY the email from Step 6.
          c. Password: at least 8 characters. Write it down somewhere safe.
          d. Click "Create account".
  YOU SEE One of these:
          (1) The "Screens" page with an orange "Add screen" button.

          (2) The message "Check your email for a confirmation link, then

  IF NOT  - "This account is not on the studio allowlist": see Step 15.
          - "User already registered": you created it before. Click
            "Have an account? Sign in" and sign in instead.

STEP 14. Confirm your email (only if Step 13 asked you to).
  DO      a. Open your email inbox. Find the email from Supabase titled
             like "Confirm your signup". Check spam if it is not there.
             It can take a few minutes.
          b. Click the confirmation link in the email.
          c. Go back to your website tab, type your email and password,
             click "Sign in".
  YOU SEE The "Screens" page with an orange "Add screen" button.
  IF NOT  - The link opened an error page or "localhost": that happens
            when Step 12 was done after the email was sent. Your email is
            usually confirmed anyway. Just go back and sign in.
          - Sign in says "Email not confirmed": click
            "First time? Create the owner account" again with the same
            email and password to get a new email. Or turn off
            "Confirm email" (Step 5) and sign in.
          - "Invalid login credentials": wrong email or password, or the
            email is not confirmed yet.

STEP 15. If you see "This account is not on the studio allowlist".
  WHY     The email you signed up with does not exactly match Step 6.
  DO      a. The page shows a line starting with  insert into ...
             Select that whole line and copy it (Ctrl + C).
          b. Supabase > "SQL Editor" > "New query" > paste > "Run".
          c. Back on your website click
             "I've done it - check again".
  YOU SEE The "Screens" page with an orange "Add screen" button, and the
          text "Pair a tablet, TV or PC to start."


======================================================================
  PART F - YOUR FIRST SCREEN (the Android tablet)
======================================================================

STEP 16. Open the player on the tablet.
  DO      a. On the tablet open Chrome.
          b. Type your website address followed by /player/
             for example:  https://marquee-signage.pages.dev/player/
             (do not forget the / at the end)
  YOU SEE A dark screen with "MARQUEE", the words "Pair this screen" and a
          big 6-character code with an orange dot, for example  BX4KQ7
  IF NOT  - "Cannot sign in this player": anonymous sign-ins are OFF.
            Do Step 4 again, then reload the page.
          - "Setup needed": config.js problem (Step 8 and Step 27).
          - "Cannot reach the server": check the tablet's Wi-Fi.

STEP 17. Install it as an app (so it runs full screen).
  DO      a. Tap Chrome's menu (three dots, top right).
          b. Tap "Add to Home screen" or "Install app", then "Install"
             or "Add".
          c. Go to the tablet's home screen and tap the new "Marquee"
             icon.
  YOU SEE The same code screen, now full screen with no browser bar.
          The code may be the same or new. Use the one on screen now.

STEP 18. Pair the tablet.
  DO      a. On the PC, in the studio, click the orange "Add screen".
          b. A box opens. Type the code from the tablet into the big
             box (small or capital letters both work).
          c. "Screen name": for example  Front window
          d. Click "Pair screen".
  YOU SEE - Studio: a dark "monitor" picture with your screen name under
            it. At first it may say "Waiting for first check-in". Within
            about 30 seconds the light turns green and says "ON AIR".
          - Tablet: "Paired", then the time and
            "Front window has no playlist yet."
  IF NOT  - "That code is not valid or has expired": codes last 30
            minutes and never contain 0, O, 1 or I. Close and reopen the
            Marquee app on the tablet to get a fresh code and try again.

  PART G - PUT CONTENT ON THE SCREEN
======================================================================

STEP 19. Upload pictures or videos.
  DO      a. Studio: click "Media" at the top.
          b. Click "Choose files" (right side of the dashed box), pick
             pictures or videos on your PC, click "Open".
             (Or drag files onto the dashed box.)
  YOU SEE Each file appears as a picture tile with a small label
          (IMG or VID) and the name under it. "Upload finished" pops up.
  RULES   Videos: MP4 files under 50 MB. They play with no sound.
          Pictures: JPG or PNG. Landscape pictures look best on a
          landscape screen.
  IF NOT  - An error mentioning size: the file is over 50 MB. Make it
            smaller (ask ChatGPT: "how do I make a video smaller on
            Windows for free?").

STEP 20. (Optional) Make a text slide.
  DO      a. Media page: click "Text slide" (top right).
          b. Headline: e.g.  Fresh bread daily
          c. Message: e.g.  Baked every morning at 6am
          d. Pick Background and Text colours.
          e. Click "Save".
  YOU SEE A new tile with your text on your colours, labelled TXT.

STEP 21. (Optional) Show a web page.
  DO      Media page: "Web page" > paste an address that starts with
          https:// > give it a name > "Save".
  NOTE    Many big websites refuse to be shown this way and stay blank.
          Test it on the tablet before relying on it.

STEP 22. Make a playlist.
  DO      a. Click "Playlists" at the top.
          b. Click the orange "New playlist".
  YOU SEE A white card titled "Playlist 1" with "Add media" and "Delete".
  DO      c. To rename: click on "Playlist 1", type a new name, press
             Enter.
          d. Click "Add media". Tick the items you want. Click
             "Add selected".
  YOU SEE A coloured strip at the top (one block per item, wider = shown
          longer) and a numbered list: 01, 02 ... Each row shows a small
          picture, the name, "ON AIR · Always", a seconds box, arrows,
          "Schedule" and a red X.
  DO      e. Seconds: click the number box and type how long to show it,
             e.g. 10. For videos, 0 = play the whole video.
          f. Order: use the up/down arrows.
          g. Remove: red X.

STEP 23. (Optional) Schedule an item.
  EXAMPLE Show "Breakfast menu" only on weekdays from 7:00 to 11:00.
  DO      a. Click "Schedule" on that row.
          b. Days: click S (Sunday) and S (Saturday) so they turn light
             (off). Dark = on.
          c. From: 07:00   Until: 11:00
          d. Click "Done".
  YOU SEE The row now says "Weekdays · 07:00-11:00" and "OFF AIR" outside
          those times.
  NOTE    "Always show" removes the schedule. The times use the tablet's
          own clock, so set the tablet's time correctly.

STEP 24. Put the playlist on the screen.
  DO      a. Click "Screens" at the top.
          b. Under your screen's monitor picture there is a drop-down that
             says "No playlist". Choose your playlist.
  YOU SEE - Studio: "Front window updated".
          - Tablet: within a few seconds (at most about 15 seconds) your
            content starts playing full screen.
          - Studio monitor picture: "NOW SHOWING" with the item's name.
  DO      c. Click "Identify". The tablet shows its name with a green dot
             for 10 seconds. Useful when you have several screens.
  IF NOT  - Tablet shows "Nothing is scheduled right now.": the playlist
            is empty, or all its items are scheduled for other times.
          - Nothing changes after 1 minute: in the studio click the "..."
            button next to "Identify" > "Re-download content".

STEP 25. Keep the tablet on all day.
  DO      On the tablet:
          a. Keep it plugged into the charger.
          b. Settings > Display > Screen timeout > the longest option.
          c. Settings > Apps > Chrome > Battery > "Unrestricted"
             (wording differs by brand: "Don't optimise", "No
             restrictions").
          d. Optional, stops people leaving the app: Settings > Security
             (or "Security and privacy" > "More security settings") >
             "App pinning" / "Pin windows" > ON. Open Marquee, open
             recent apps (square button or swipe up and hold), tap the
             Marquee icon at the top of its card > "Pin".
             To unpin: hold Back and Recents together (or swipe up and
             hold).
  NOTE    Menu names differ between brands. Use PROMPT 2 with your
          tablet's brand and model if you cannot find one.

          awake...".
  UNDO    Windows key + R > type  shell:startup  > Enter > delete

======================================================================
  PART I - CHANGING THINGS LATER
======================================================================

STEP 27. Uploading the website again (only if you changed a file in
         the "web" folder, e.g. config.js).
  DO      Cloudflare > "Workers & Pages" > click "marquee-signage" >
          "Create deployment" (or "Upload new version") > drag the "web"

          Then in the studio, for each screen: "..." > "Restart player".

STEP 28. Running a new schema.sql (only if you get a new version).
  DO      Same as Step 3. Your screens, media and playlists are kept.

EVERYDAY TASKS
- Change content:        Media (add) > Playlists (add/remove/reorder).
                         Screens update by themselves.
- Different content on different screens: make more playlists, choose
                         one per screen on the Screens page.
- Portrait (standing) TV: Screens > "..." > Rotation > Portrait > Save.
- Black bars around pictures: Screens > "..." > Image fit >
                         "Fill screen (crop)" > Save.
- Screen stuck:          Screens > "..." > "Restart player".
- Screen shows old stuff: Screens > "..." > "Re-download content".
- Remove a screen:       Screens > "..." > "Remove screen" (the device
                         goes back to showing a code).
- Add another tablet/TV: repeat Steps 16, 17, 18 and 24 on it.
